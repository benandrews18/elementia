Quark Breakpoint Tuner

Two kinds of Display Mat check. A quiet check happens every time a player travels: the mat's Quark score sets that trip's bonus dice (thin smooth lines, the table below). Every 3rd visit is an official check (shutter, Lock-In, orders): its breakpoints are the quiet ones plus the bump, so the thick line — what a player actually has to beat at each visit — jumps up at visits 3, 6, 9… and drops back after. The official result is also a dice floor for the next 3 visits. Drag the dots (quiet values) or use the sliders, then copy the code back into chat. The purple band is simulated runs (middle half shaded, median solid, 10th/90th percentile dashed); coloured lines are your runs' board checks. The table's last column says, live, what share of simulated runs clear each breakpoint at that visit.

Press near any dot and drag up or down to set it; keep dragging sideways to sketch the same tier across neighbouring visits (snaps to 5; values can go up to 9,995 even if the chart is zoomed in). Each tier should stay at or above the one below it — a cell gets a red border if it doesn't. Red text means the value is above the best mat the simulator ever reached (dashed red line on the chart), so practically nobody clears it. Smooth & scale: each line is a best-fit S-curve through your hand-drawn table (dotted lines); the slider scales all four together. Dragging a dot still works, but moving the slider redraws every line from the curves — press Refit to table first to keep your edits.
