Quark Breakpoint Tuner

Two kinds of Display Mat check. A quiet check happens every time a player travels: the mat's Quark score sets that trip's bonus dice (thin smooth lines, the table below). Every 3rd visit is an official check (shutter, Lock-In, orders): its breakpoints are the quiet ones plus the bump, so the thick line — what a player actually has to beat at each visit — jumps up at visits 3, 6, 9… and drops back after. The official result is also a dice floor for the next 3 visits. Drag the dots (quiet values) or use the sliders, then copy the code back into chat.
