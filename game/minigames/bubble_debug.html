🌊 Bubble Pop: Tap Diagnostics

hit (inside the tapped bubble's own visible circle) corner steal (tap landed OUTSIDE the bubble's circle, in its invisible square hit-box) ghost (a bubble's circle visually contains this point, but no live bubble was the actual event target) miss (open water)

Runs the real, unmodified ocean-bubbles.js — nothing here changes how the shipped game behaves. This just watches from outside: every tap is classified against the bubbles' actual DOM hit-boxes, so you can see exactly what the game "saw" versus what you visually tapped. Corner steal is the "wrong bubble popped" bug: border-radius only rounds the paint, not the hit-test area, so a bubble's true click region is its full square bounding box -- a newer, still-low bubble sitting on top in stacking order can silently catch a tap meant for a different bubble nearby, via a corner well outside its own visible circle.
