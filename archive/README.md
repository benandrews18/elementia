# Archive

Experiments and retired tooling, kept for reference. **Nothing here is
maintained or kept in sync with the game.** Scripts may not run (paths and
data sources have moved). Don't read these for current rules, recipes or
points: the game (`game/js/data.js`, `game/js/model.js`) is the source.

| Folder | What it was | Status |
|---|---|---|
| `landscape/` | Landscape/browser edition (`elementia_landscape.html`, plan, mockups, `build_minigames.py`). Forked from portrait on 2026-09-18. | Paused. If resumed, start a fresh port from the current portrait `game/`, not from this file. |
| `cardgame/` | Solo card-game prototype. | Experiment, not updated. |
| `boardgame/` | Board-game prototype. | Experiment, not updated. |
| `side-scroller/` | Side-scroller prototype. | Experiment, not updated. |
| `simulation/` | Python reachability/pathing/calibration simulators. Read the old `build_guide.py` data. | Out of date. |
| `tools/` | Balance simulator, Story Mode simulator, point-curve tool. Each embeds its own data snapshot. | Out of date. |
| `handoff/` | Old suit and collection CSVs, board-game handoff notes. | Superseded by tables in `game/js/model.js` and `game/js/mat-scoring.js`. |
| `field-game-pdfs/` | Non-Classic PDFs from the field-game era (full deck, print runs, item reference, full station guide). Not tracked in git. | Retired. |
