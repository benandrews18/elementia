### How lucky was this run?

The table above is the **best case**: the dice arranged as favourably as
the stations allow, leaving **9** tokens uncoverable.
With **average dice** — one of each of a station's six faces per visit —
the same run comes up **28** tokens short instead.

So between 9 and 28 tokens had to come from conversions or
from luckier-than-average rolls. The real run sits somewhere in that band.
